# EterfaceID

Build a B2B SaaS/API product for KYC/KYB/AML similar to ComplyAdvantage, Plaid and Truloo all in one - to be called "eterfaceID". The system should comply with FINTRAC and BoC PSP (RPAA) and support all industries including Fintech. Key features are: 

1. Digital KYC/KYB

Plaid Identity Verification supports:

 Government ID verification

 Passport/ID/document verification

 Name verification

 Date of birth

 Address

 ID numbers

 Phone verification

 Selfie verification

 Liveness

 Face-to-ID matching

 Fraud signals

 Device/network risk

 Email/phone risk

AML sanctions/PEP screening 

This is where Plaid Monitor becomes particularly useful.

Plaid Monitor provides screening against:

 Sanctions lists

 PEP lists

 Government watchlists

 Other watchlists

 Ongoing rescreening
